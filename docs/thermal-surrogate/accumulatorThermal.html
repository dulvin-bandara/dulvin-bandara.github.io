accumulatorThermal

Reduced-order transient thermal model of a Formula Student battery accumulator.

The model is composed of two stages. A Gaussian process surrogate, fitted to full-car CFD results, maps vehicle velocity and front and rear ride height to the cooling air mass flow captured at the sidepod inlet. A channel-resolved transient thermal network then converts that mass flow into cell temperatures over time.

Mass flow is an intermediate quantity rather than a user input, so the model takes the three variables a vehicle dynamicist controls and returns the quantity a thermal engineer needs.

The usual entry point is vehicle.AccumulatorModel::

from accumulatorThermal import AccumulatorModel, VehicleCondition
from accumulatorThermal import AirProperties, CellProperties, PackGeometry
from accumulatorThermal import constantCurrent, fitBoth, loadSweep

data = loadSweep("data/normalisedSweep.tsv")
surrogate, metrics, _, _ = fitBoth(data)

model = AccumulatorModel(
    surrogate=surrogate,
    cell=CellProperties(),
    air=AirProperties(),
    geometry=PackGeometry(),
    currentProfile=constantCurrent(73.0),
    inletTemperature=313.15,
)
result = model.predict(
    VehicleCondition(15.0, 32.0, 34.0),
    initialTemperature=303.15,
    duration=2400.0,
)

The thermal network can also be driven directly with a known mass flow, bypassing the surrogate, which is how the verification cases in validation are run.

Module map:

  • properties -- frozen cell, air and pack geometry database
  • correlations -- Reynolds, Nusselt and convective heat transfer coefficient
  • heat_source -- ohmic and entropic heat generation, current profiles
  • network -- the assembled 120-cell network and the air temperature march
  • integrators -- RK4, backward Euler, stability limit, closed-form solution
  • validation -- energy balance closure and temporal convergence
  • baseline -- single-node lumped pack, for comparison
  • surrogate -- Gaussian process and polynomial response surface
  • vehicle -- the composed model
